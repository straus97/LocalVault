# Security Policy

## Supported version

Security fixes are currently considered for:

| Version | Supported |
| --- | --- |
| 1.0.x | Yes |

## Reporting a vulnerability

Please do not publish exploitable security vulnerabilities in a public
GitHub issue before the maintainer has had an opportunity to review them.

Contact the project owner privately when possible.

When reporting a vulnerability, include:

- the affected LocalVault version;
- Windows version;
- steps required to reproduce the issue;
- expected and actual behavior;
- whether the issue can expose plaintext vault data, master passwords,
  clipboard contents, or encrypted vault integrity.

Do not include real passwords, real vault files, or other personal secrets
in vulnerability reports.

## Scope

LocalVault is a local desktop password manager.

The application does not claim to protect secrets from malware,
keyloggers, process-memory inspection, or a compromised operating system
while the vault is unlocked.
